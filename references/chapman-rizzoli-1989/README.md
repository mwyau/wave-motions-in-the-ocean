# Chapman and Malanotte-Rizzoli notes (1989)

These five PDFs are scans of the 1989 *Wave Motions in the Ocean* notes by David C. Chapman and Paola Malanotte-Rizzoli. They are the source used to check this reconstruction. When source fidelity matters, check the wording, equations, page layout, and figures against these PDFs.

Later notes and outside references may help find an error, but they do not change what the 1989 PDFs contain. Do not edit the PDFs.

The project credits James Pringle's website for preserving the scans. The online copy used by the project is the [original online source](https://oxbow.sr.unh.edu/ChapmanRizzoli/Wave_Motions_in_the_Ocean.html).
