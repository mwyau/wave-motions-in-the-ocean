# Third-party typefaces

The TeX publication pipeline uses the following open-source typefaces. Font files are build dependencies supplied by TeX Live; they are not vendored in this repository.

- **STIX Two Text and STIX Two Math** — STIX Fonts Project / STI Pub Companies; the STIX Two redesign was undertaken by Tiro Typeworks. Distributed under the **SIL Open Font License 1.1**. Official project: https://www.stixfonts.org/
- **Source Sans 3** — Adobe. Distributed under the **SIL Open Font License 1.1**. Project: https://github.com/adobe-fonts/source-sans

The SIL Open Font License permits use of these fonts in printed and electronic documents and permits embedding in PDFs. The OFL applies to the font software, not to documents created with the fonts; it therefore does not change the CC BY-NC-SA 4.0 license of this digital edition.
